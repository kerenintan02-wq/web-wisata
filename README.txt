WEBSITE JELAJAH PANTAI - 3 HALAMAN

Isi folder:
1. index.html      = halaman Beranda
2. destinasi.html  = halaman Destinasi
3. kontak.html     = halaman Kontak
4. style.css       = desain dan pengaturan tampilan
5. script.js       = interaksi formulir kontak

CARA MENJALANKAN:
1. Ekstrak file ZIP.
2. Buka folder website_wisata_pantai.
3. Klik dua kali file index.html.
4. Website akan terbuka di browser.
5. Gunakan menu Beranda, Destinasi, dan Kontak untuk berpindah halaman.

CATATAN:
- Website ini menggunakan HTML, CSS, dan JavaScript sederhana.
- Foto pada halaman diambil dari Unsplash sehingga membutuhkan koneksi internet.
- Formulir kontak hanya simulasi di browser, belum mengirim pesan ke email/server.
